Данный плагин позволяет извлекать все типы аннотаций из PDF и записывает их в заметки вашего хранилища с автоматическим форматированием. Для импорта доступен выбор типов аннотаций, диапазонов страниц и дней создания комментариев, а шаблоны позволяют форматировать каждый тип отдельно. Группируйте аннотации по папке, файлу, дате и теме и отправляйте их в текущую заметку, в новую, либо каждую аннотацию в отдельную заметку.


## Фичи

### 1. Извлечение аннотаций из PDF внутри и вне хранилища

Извлекайте выделенный, подчёркнутый, зачёркнутый текст и волнистое подчёркивание, а также комментарии-стикеры и свободный текст на странице из ваших PDF. Источники импорта: файл, который вы читаете, все PDF в текущей папке, а также путь из буфера обмена — для тех PDF, которые вы не хотите копировать в хранилище. Путь из буфера обмена может вести и к папке: тогда будут прочитаны все PDF в ней, каждый в свою заметку.

### 2. Расширенное меню извлечения для тонкой настройки импорта

Уже извлекли аннотации из PDF, затем сделали новые и хотите импортировать только их? Откройте расширенное меню и сузьте извлечение до определённых страниц (`25-50`, `25, 26, 30`, `i-viii`), до определённых дней, когда аннотации были созданы, — и до определённых цветов, которыми они помечены. Список цветов собирается из самого файла: единой палитры у формата PDF нет, каждая читалка использует свою.

### 3. Шаблоны форматирования для каждого типа аннотаций

Настройте шаблон по умолчанию, который будет оформлять все типы аннотаций, или создайте отдельные шаблоны для конкретных типов. Очистите шаблон — и этот тип аннотаций снова будет использовать шаблон по умолчанию. Таблица доступных переменных расположена прямо над редактором для вашего удобства. Наконец, теги, содержащиеся в ваших аннотациях, можно автоматически переносить в свойство `tags` заметки для экономии времени.

### 4. Группировка, заголовки и правила именования заметок

Группируйте аннотации по папке, по файлу, по дню создания и по теме (первая строка каждого комментария) — именно в этом порядке группировки вложены друг в друга. Группировки по папке и по файлу действуют, только когда аннотации извлечены из нескольких папок или файлов. Опционально в заметки можно автоматически добавлять заголовки групп. Заголовки, которые пишут ваши шаблоны и сами комментарии, можно вкладывать в заголовки групп: самый верхний из них встанет сразу под последним заголовком группы, порядок между собой они сохранят — и структура заметки останется правильной при любом наборе включённых заголовков групп. Заметки могут именоваться по шаблону, а при извлечении в отдельные заметки — по теме самой аннотации; там же задаётся подпапка, которая тоже создаётся по шаблону. При извлечении в отдельные заметки их можно раскладывать по разделам самого PDF: закладки документа превращаются во вложенные папки. Настройки разделены по типу извлечения: общие правила, извлечение в отдельные заметки и извлечение в общие заметки.


## Установка

### Вариант 1: Магазин плагинов Obsidian

1. Находясь в настройках Obsidian, откройте вкладку "Сторонние плагины" и нажмите на кнопку "Обзор".

2. В поисковой строке введите `Classy PDF Extractor`, нажмите на результат, затем на кнопки "Установить" и "Включить".

Альтернативно, вы можете установить плагин, перейдя на сайт сообщества по ссылке: [https://community.obsidian.md/plugins/classy-pdf-extractor](https://community.obsidian.md/plugins/classy-pdf-extractor)

### Вариант 2: плагин BRAT

Если вы хотите протестировать бета-версию плагина или предыдущие обновления, вы можете сделать это с помощью плагина `BRAT`:

1. Из официального магазина плагинов Obsidian установите плагин `BRAT`.

2. В настройках `BRAT` найдите раздел "Beta plugin list" и нажмите на кнопку "Add beta plugin".

3. В появившемся окне вставьте ссылку на репозиторий плагина `Classy PDF Extractor`: [https://github.com/pan4ratte/obsidian-classy-pdf-extractor](https://github.com/pan4ratte/obsidian-classy-pdf-extractor)

4. В пункте "Select a version" выберите нужную версию и нажмите на кнопку "Add plugin". Плагин автоматически установится и будет готов для использования.
